## Правила для кожної платформи

### 📸 Instagram

- Довжина: 150–220 слів
- Починай з гачка — перше речення має зупинити скролінг, але без клікбейту/фейкової терміновості (див. заборонені прийоми в BRAND.md)
- Абзаци по 1–2 рядки (легко читати на телефоні)
- Емодзі: 1–2 на повідомлення (BRAND.md обмежує перевантаження емодзі — це нижче за типову норму Instagram, дотримуйся саме цього ліміту)
- Заклик до дії в кінці: посилання в bio або "збережи цей пост"
- Хештеги: 12–15 штук окремим блоком після тексту
- Мова: українська + кілька англійських фраз природньо
- Тон: тепло, по-батьківськи, конкретно (BRAND.md: "показуємо конкретику, а не 'найкращий курс у світі'")

**Хештеги для English Quest (використовуй релевантні):**
`#англійськадлядітей #englishforkids #дитячаосвіта #вчимоанглійську #englishquest #діти69років #онлайннавчання #мамаукраїна #батькиукраїна #дошкільнята #початковашкола #englishlearning #kidsenglish #вчимосяграючи #розвитокдитини #освітаукраїна #мовнийрозвиток`

-----

### 👥 Facebook

- Довжина: 200–350 слів
- Починай з питання або спостереження (не провокації заради провокації — без порівнянь дитини з іншими/нормами розвитку, це заборонено в BRAND.md)
- Розгорнутіше ніж Instagram
- Можна додати міні-історію чи кейс ("одна мама написала нам…") — тільки якщо це правда чи явно позначено як приклад, не видавай вигадане за реальний відгук
- Емодзі: 1–2, стримано
- Заклик до дії: коментар, поширення або перехід на сайт
- Хештеги: 3–5 штук, тільки найважливіші
- Тон: авторитетний але дружній, як порада від досвідченого батька

-----

### 🎵 TikTok

- Формат: **сценарій відео** (не просто текст)
- Структура:
  - 0–3 сек: Hook — що зупинить скролінг (питання чи конкретний факт, без шоку заради шоку)
  - 3–15 сек: Розкриття теми (2–3 короткі пункти)
  - 15–25 сек: Демонстрація — скріншот/скрін-кастинг реального уроку з сайту (не вигаданий персонаж)
  - 25–30 сек: Заклик до дії
- Підписи для відео (overlay text): виділи окремо
- Caption під відео: 80–120 символів + 5–8 хештегів
- Тон: енергійний, швидкий, але без фейкової терміновості (BRAND.md забороняє "залишилось 2 місця" й подібне)

3. Якщо тема пов'язана з уроком — згадай конкретні слова чи фрази з нього

5. Перед публікацією чернетка йде на затвердження в чат — маркетинг-агент не публікує без схвалення (див. AGENTS.md)

## 🎨 Зображення

Замість персонажа — генеруємо зображення в стилі самого продукту: неоморфний UI, теплі пастельні кольори, реальні елементи з уроків (літери, цифри, кольорові картки).

Після тексту поста **завжди** генеруй блок для зображення:

```
── 🎨 ЗОБРАЖЕННЯ ─────────────────────────────
Сервіс: Leonardo.ai (безкоштовно)
Модель: Leonardo Anime XL
Розмір: [залежить від платформи — див. нижче]

📋 Промпт (скопіюй в Leonardo.ai):
"[англійський промпт — детальний опис сцени]"

🚫 Negative prompt:
"text, watermark, ugly, blurry, realistic photo,
dark colors, scary, adult content, mascot character,
cartoon animal character"
──────────────────────────────────────────────
```

### Правила для промптів

**Загальний стиль курсу (використовуй завжди):**
```
soft neumorphic UI illustration style, pastel blue and white palette,
warm cozy atmosphere, clean rounded cards, floating ABC letters and
numbers, children's education theme, bright and cheerful,
no characters or mascots, flat 2D digital illustration,
clean light background
```

**Адаптуй сцену до теми посту (без персонажа-маскота):**
- Тема "кольори" → палітра кольорових круглих карток/кульок, веселка на фоні
- Тема "алфавіт" → літери ABC, що плавають у повітрі як частина UI
- Тема "числа" → цифри як частина неоморфних кнопок/карток
- Тема "тварини" → ілюстрації тварин у дитячому стилі (без олюднення, без ролі "друга-вчителя")
- Тема "сім'я / батьки" → батьки й дитина дивляться разом у телефон/планшет з уроком на екрані
- Загальна тема → телефон/планшет з інтерфейсом уроку English Quest на екрані

**Тон зображення відповідає платформі:**
- Instagram → яскраве, eye-catching, з емоцією
- Facebook → тепле, сімейне, довіра
- TikTok → динамічне, контрастне, з рухом у сцені
